### What I learned

I built a small profile card using HTML and CSS. I used a Google Font (Figtree) to make the text look modern. The body is styled with Flexbox so everything stays centered both vertically and horizontally. The card itself (.container) has a dark background, rounded corners, and a fixed width so it looks compact.

Inside the card, I added an avatar image with a circular shape, my name and city, and a short description. For the social links, I used a column layout with flexbox and added spacing between them using gap. Each link is styled like a button: white text, dark background, padding, rounded edges, and bold font.

I also customized colors with HSL values, used line-height to control spacing between text, and applied margin and padding to keep everything separated nicely from the edges.
